# Graffiti & Culture | Educational Arts Platform 🎨
An immersive educational guide exploring the intersection of digital photography, urban culture, and global street art.

### 🗺️ Key Technical Features
- **Split-Section Architecture**: A modern, high-impact landing page design utilizing a fixed/scrolling split-screen layout for visual storytelling.
- **Interactive Progress System**: A "Steps-based" navigation container with active-state styling, allowing users to track their journey through the curriculum.
- **Optimized SVG Integration**: Strategic use of inline Scalable Vector Graphics (SVGs) for crisp, performance-oriented iconography across all device resolutions.
- **Modular Navigation**: Custom hover-effect logic applied to an interconnected network of specialized sub-pages (Photography, Culture, Visual Library).

### 🛠️ Tech Stack
- **Compatibility**: Mobile iOS/Tablet/iPad
- **Frontend**: Vanilla JavaScript (ES6+), HTML5
- **Styling**: CSS3 (Flexbox-driven Step-Containers, Split-Section Grids, and Interactive Hover States)
- **Vector Graphics**: XML-based SVG icons for resolution-independent UI.

### 🌏 Educational Goal
The Graffiti Street Art Project serves as a digital bootcamp, bridging the gap between traditional photography and modern street culture. It showcases an ability to organize complex information into an intuitive, visually-engaging learning path.
